## Dokumentasi Kegiatan Workshop (Day 1)

### 1. Rangkuman Materi
* **Prompt Engineering:** Teknik merancang instruksi agar AI memberikan hasil yang akurat[cite: 7]. Struktur prompt yang baik terdiri dari **Role** (Peran), **Task** (Tugas), **Context** (Konteks), dan **Format** (Hasil akhir)[cite: 10].
* **Git vs GitHub:** 
  * **Git:** *Version Control System* untuk melacak perubahan kode secara lokal di komputer[cite: 17].
  * **GitHub:** Platform berbasis web untuk menyimpan repository Git secara *online* dan kolaborasi tim[cite: 17].
* **Essential Git Commands:**
  * `git init` : Memulai repository baru[cite: 18].
  * `git add .` : Memasukkan file ke *staging area*[cite: 18, 23].
  * `git commit -m "pesan"` : Menyimpan perubahan secara lokal[cite: 18].
  * `git push origin main` : Mengunggah perubahan ke GitHub[cite: 20].

### 2. Poin Penting & Pengetahuan Baru
* Memberikan konteks yang spesifik (seperti menentukan peran dan batasan/constraints) saat memakai AI sangat membantu menghasilkan kode yang presisi[cite: 9, 11].
* Memahami alur kerja Git dari *Working Directory* $\rightarrow$ *Staging Area* $\rightarrow$ *.git Directory*[cite: 16].
* Menghubungkan project lokal ke remote repository di GitHub serta melakukan *push* secara berkala[cite: 20].

### 3. Pendapat Pribadi
Workshop hari pertama ini seru dan membuka wawasan baru tentang bagaimana menggabungkan kecepatan *AI-assisted development* dengan sistem manajemen versi yang rapi menggunakan Git dan GitHub. Materinya sangat *relate* dan kepake banget buat kebutuhan ngoding ke depannya.
